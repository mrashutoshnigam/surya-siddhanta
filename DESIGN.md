# Surya Siddhanta interface design

The existing runtime tokens in `frontend/src/styles.css` are canonical. Light canvas is `#ffffff`, ink `#0a0b0d`, soft surface `#f7f7f7`, hairline `#dee1e6`, and primary action `#0052ff`. Dark-theme equivalents remain owned by that file. Feature styles consume these variables rather than introducing another palette.

The audience includes astronomy learners and readers inspecting historical calculations. Distinguish results, historical rules, commentary, and modern reference evidence. Body and heading fonts use the existing system stack; measurements use the existing monospace stack. Visualizations must state their frame and avoid implying physical scale where only angles are represented.

Panchanga opens at the current browser-local date and clock minute with an explicit UTC offset. The shared DateInput's withTime variant presents separate whole-day and native time fields; it preserves fractional-day API requests and adds Now to restore the current browser date/time/offset. Whole-day and existing fractional-day variants on other pages are unchanged. Time inputs retain platform-owned popup/keyboard behavior. The result heading displays the server's evaluated timestamp; time and timezone edits trigger recalculation, pending results are labeled, and superseded responses are ignored.

The Learning Lab uses a large longitude dial, a selectable numbered calculation sequence and a separate research panel. Native form controls, shared DateInput and Slider components own inputs. The existing shell, theme toggle and ErrorBox own navigation, theme and error presentation. Keep loading and result dates distinct, offer retry, never let late responses replace newer selections, and provide text equivalents for plotted values. No remote font or image dependency is needed for this route.

The learning directory at /learn leads to seven body lessons and a separate Rahu lesson. Shared body lessons own correction interactions; LessonContext owns seasonal, tithi and paired-planet explanations. lessonDates owns whole-day validation and formatting. Rahu uses the same date primitives, theme and feedback rules, with a dedicated node diagram. Mobile comparisons can scroll within their table wrapper; the document itself must not overflow. Existing select/listbox controls intentionally remain native, with platform-owned popup geometry and keyboard behavior, recorded in frontend/premium-ui.json.

The Universe Explorer at /universe is an additional beginner surface. Its signature is a dark, spacious astronomical scene beside a theme-aware fact/chat panel, with a shared timeline below. It inherits the existing runtime tokens, typography, sidebar and theme switch. Realistic local planet maps are credited to Solar System Scope under CC BY 4.0; procedural textures cover loading failures. The historical Earth-centered model and independent JPL modern model are always labeled. Globe size, screen distance, surface orientation and visible spin rate are illustrative. Exact numerical facts carry their own model and evaluation time. Keyboard body buttons and a selectable 2D map provide equivalent access; reduced motion starts playback paused and stops illustrative surface spin. Guided tours restore the preceding exploration state when exited. Chat offers user-activated, allowlisted tours, never automatic scene commands.

The timeline's native datetime-local calendar delegates popup geometry and locale to the platform, with an explicit UTC-offset selector and app-owned Gregorian validation; shared whole-day DateInput fields remain a typed variant. On phones, time controls sit immediately below the scene, before planet details, and the full application navigation is collapsible.

Active tours sit directly above the visualization, with keyboard-focused step headings and persistent Back/Next/Replay/Exit controls. Motion controls independently demonstrate surface spin and orbital progression; selected-body axes/arrows explain each. Labels avoid collisions, and focus includes the relevant origin or Earth/Moon pair. The Mars lesson uses daily exact historical readings from October 2024–April 2025, an accessible longitude chart, dated direction markers and a reference ring. Time scrubbing is a native range input with day-step buttons and a bounded tour interval; all jumps preserve the canonical UTC instant and pause playback. Beginner facts precede expandable numerical results, whose exact timestamp stays distinct from scene time. Chat messages retain their captured body/model/instant even after the learner changes the scene. These teaching components inherit the existing tokens; no new font or palette is introduced.

The first home-page visit (`/`, redirecting to `/positions`) opens the academic project introduction. `ProjectWelcome` owns the content and dismissal preference (`ss.project-introduction.dismissed` in localStorage); a footer “About this project” button reopens it on every route. The shared footer credits Ashutosh Nigam, Roll No: M25AI2006, and Indian Institute of Technology Jodhpur alongside the route-specific calculation source. Like `TermDialog`, it uses native modal dialog semantics for focus containment, Escape and an inert background. The initial heading receives focus; dismissal restores focus to the footer button. The title page and resource column consume existing theme tokens; the official locally bundled IIT Jodhpur logo retains its original colors on white. On narrow screens the body scrolls while the close control and primary action remain reachable. Direct links to other routes do not auto-open the introduction.

The sidebar's “Surya Siddhanta AI” action and floating chat icon open one shared ChatPanel without navigation. Its tabs are AI Chat first (with a chat-bubble icon) and Terms second, with selected-state underlines and ArrowLeft/ArrowRight/Home/End keyboard navigation. Both tabpanels stay mounted to preserve the conversation, draft, location, pending request and glossary filter across routes, tab switches and closing; a reload starts a fresh chat session. The panel keeps one width and one close control across tabs. It is non-modal on desktop, docks at 1884px (264px navigation + 1200px content + 420px panel), and overlays at narrower desktop widths. Below 768px both tabs share the same full-screen native modal with focus containment, Escape dismissal, body scroll lock and safe-area padding. A term definition opens as a nested modal; its Escape dismisses only that definition. Closing the panel restores focus to its opener. The previous wide-screen glossary open preference is retained. Legacy /chat links redirect to /positions with AI Chat selected. Existing theme tokens, Markdown, location inputs, calculation traces and chapter citations remain canonical; failed requests offer Retry without duplicating the displayed question.
